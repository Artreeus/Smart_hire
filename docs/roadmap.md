# Roadmap

Potential next phases include:

- Transactional email delivery and templating
- OAuth and optional multi-factor authentication
- Recruiter team membership and organization permissions
- Interview calendar integrations
- Real-time notification delivery
- Candidate profile visibility controls
- Account export and deletion
- Resume version selection per application
- Advanced analytics and CSV exports
- Duplicate-listing similarity search
- Malware scanning and content moderation queues
- Automated unit, integration, browser, and accessibility test suites

Roadmap items should be prioritized against user research, security risk, academic scope, and deployment constraints.
